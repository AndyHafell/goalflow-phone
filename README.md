# GoalFlow — phone

The built phone client for GoalFlow, hosted so an iPhone can reach it from
anywhere rather than only from the same wifi as the Mac.

This repository holds **build output only** — no application source. It is
regenerated by `npm run build:phone-pwa` in the private GoalFlow repo and
force-pushed here; edits made in this repository will be overwritten.

## About the key in the bundle

The Supabase URL and *publishable* key are compiled into `assets/`, and that is
by design — they are meant to ship in a client. They are not what protects the
data. Row level security is: every table pins every row to the signed-in user,
so the key gets an anonymous visitor as far as a login prompt and no further.

The `service_role` key, which does bypass row level security, is not here and
must never be.
